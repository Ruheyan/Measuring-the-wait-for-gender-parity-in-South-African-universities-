# Research Data and Code

Data, code and selected outputs for the study "Measuring the Wait for Gender Parity in South African Universities", using survival analysis to examine female academic staff representation from 2000 to 2023.

## Repository Contents

- **Data:** Datasets used in the analysis.
- **Code:** Scripts used for data processing, statistical analysis, and visualisation.
- **Outputs:** Selected results, figures, and tables generated from the analysis.

## Reproducibility

The materials are provided to support transparency and reproducibility of the research.
